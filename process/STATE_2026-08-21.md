## Three things that will bite whoever resumes

**1. `build.bat` writes a stale PDF.** It produces a fresh *log* while never rewriting the PDF, so
the gate reads green off a day-old artifact. This cost most of a morning. **Always run the cycle
directly — `pdflatex · biber · makeindex · pdflatex · pdflatex` — and check the PDF's modification
time against the run.** A green log proves pdflatex ran; only the timestamp proves it wrote.

**2. The edition toggle must be flipped back.** The master sits at `\digitaleditiontrue` (line ~125
region, anchored on the trailing comment). Print builds flip it to false, build, and flip back. If a
session ends mid-flip the committed state is wrong.

**3. `ots` needs a new terminal.** The OpenSSL shim is on the persistent user PATH as of today, but
already-running processes keep their old PATH, which looks exactly like the fix failing.
