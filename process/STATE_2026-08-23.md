## Three things that will bite whoever resumes

**1. `build.bat` writes a stale PDF — and so does an open PDF reader.** The 21 August note warned
about the first; today the second bit, from a different direction. **Foxit had the interior open, so
pdflatex could not write it, and the build produced a clean log against a two-day-old artifact.**
Identical symptom, different cause. Run the cycle directly — `pdflatex · biber · makeindex ·
pdflatex · pdflatex` — and **check the PDF's modification time against the run**. A green log proves
pdflatex ran; only the timestamp proves it wrote. If the mtime will not move, look for a process
holding the file before you look at the LaTeX.

**2. The edition toggle must be flipped back.** The master sits at `\digitaleditiontrue`. Print
builds flip it to false, build, and flip back. Verify by checking the manuscript diff contains
nothing but your intended prose change.

**3. `ots` needs a terminal opened after the PATH fix.** Unchanged from 21 August, and it worked
first try today.
