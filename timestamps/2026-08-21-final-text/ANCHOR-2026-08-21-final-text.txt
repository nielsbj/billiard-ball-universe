ANCHOR — 2026-08-21 — the final text of the first edition (OTS interim)
================================================================================

WHAT THIS IS
------------
An INTERIM protection stamp, in the sense of the OpenTimestamps runbook's Rule 2.
It is NOT the release anchor. The release anchor (OTS-3) is a separate, later
event, tied to the tag `first-edition-1.0` and fired only after the physical
proof is approved.

WHY IT EXISTS
-------------
The only prior anchors for this book are from 30 July 2026 (OTS-1/OTS-2) and
cover a draft of roughly 142 pages. Everything since then — the hostile read
(P1–P16), the reference census, the index, both ruled-in plates, the ISBN and
its EAN-13, the sanguine cover, the pre-release audit that found the shipping
build was still the draft build, and the patches P17, P18 and P19 including the
closing concession paragraph — lies outside every existing anchor.

The release anchor is deliberately sequenced after proof approval because it
wants the tagged commit hash. That is correct for proving WHAT WAS PUBLISHED.
It is not sufficient for proving WHEN THE TEXT EXISTED. This anchor closes that
gap and nothing else.

A WARNING ABOUT THE PDFs
------------------------
pdflatex embeds a build timestamp, so rebuilding from the same sources does NOT
reproduce these bytes. The three PDF proofs are therefore only worth something
while these exact files survive. The .tex/.bib proofs above do not have this
problem: they are committed, and git preserves them byte-exact forever.

If the PDFs are lost, nothing important is lost — the sources are anchored, and
the sources are what authorship rests on.

WHAT IS NOT CLAIMED
-------------------
- Not the published edition. No tag exists; the repository is private; no proof
  copy has been printed or approved.
- Not a claim that this text is unchanged from here. Proof findings are expected
  and will be patched; they change the price of a correction, not its
  possibility.
- Not a substitute for OTS-3.

This file is frozen. It is itself stamped, so editing it after stamping would
break its own proof.
